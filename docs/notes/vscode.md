# 1. Visual Studio Code

## Atajos útiles

| Atajo | Acción | Descripción |
|---|---|---|
| `Ctrl + S` | Guardar | Guarda los cambios del archivo actual |
| `Ctrl + Z` | Deshacer | Deshace la última modificación |
| `Ctrl + Y` | Rehacer | Recupera una modificación deshecha |
| `Ctrl + F` | Buscar | Busca texto dentro del archivo actual |
| `Ctrl + W` | Cerrar pestaña | Cierra la pestaña actual |
| `Ctrl + Shift + V` | Preview Markdown | Muestra el Markdown renderizado sin modificar el archivo |
| `Ctrl + Shift + P` | Command Palette | Abre el buscador de comandos y funciones de VS Code |
| `Ctrl + `` | Terminal | Abre o cierra la terminal integrada |

## Command Palette

Abrir:

```text
Ctrl + Shift + P
```

Permite buscar y ejecutar funciones de VS Code sin tener que encontrarlas manualmente en los menús.

Ejemplo que utilizaremos con Python:

```text
Python: Select Interpreter
```

Permite seleccionar qué instalación o entorno de Python utilizará el proyecto.

## Markdown

Los archivos `.md` utilizan Markdown, un formato de texto muy utilizado para documentación y repositorios de GitHub.

Para editar el archivo se trabaja directamente sobre:

```text
learning_notes.md
```

Para visualizar cómo quedará renderizado:

```text
Ctrl + Shift + V
```

La previsualización no modifica el archivo original.

Para cerrar la previsualización:

```text
Ctrl + W
```
